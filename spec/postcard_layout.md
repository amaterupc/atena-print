# 年賀ハガキ・宛名レイアウト仕様書

本アプリケーションにおける年賀ハガキ（宛名面）の要素配置に関する仕様を定義します。
配置は日本郵便の定形郵便物および年賀ハガキの推奨規格に基づいています。

## 1. 宛先郵便番号

印刷済みの7桁の赤枠に合わせて数字を配置します。

- **基準位置**:
    - **上端**: 上辺から 12.0mm
    - **右端**: 右辺から 8.0mm
    - 配置基準: 右上（Flexboxによる右寄せ配置）

- **フォント**: `OCR-B`, `monospace` (等幅フォント推奨)
- **サイズ**: 13pt (約4.5mm)

- **文字配置 (ピッチ)**:
    - **各数字枠**: 幅 5.7mm
    - **枠間隔**: 1.3mm
    - **ハイフン部**: 3桁目と4桁目の間に 7.2mm のスペースを挿入
    - **ハイフン文字**: 出力しない

| 桁 | 要素幅 | 右余白 | 備考 |
|:---:|:---:|:---:|:---|
| 1 | 5.7mm | 1.3mm | |
| 2 | 5.7mm | 1.3mm | |
| 3 | 5.7mm | **7.2mm** | ハイフン領域 |
| 4 | 5.7mm | 1.3mm | |
| 5 | 5.7mm | 1.3mm | |
| 6 | 5.7mm | 1.3mm | |
| 7 | 5.7mm | 0mm | 最終桁 |

## 2. 差出人郵便番号

ハガキ左下の差出人枠に合わせて配置します。

- **基準位置**:
    - **下端**: 下辺から 13.0mm
    - **左端**: 左辺から 6.0mm

- **フォントサイズ**: 10pt

- **文字配置 (ピッチ)**:
    - **各数字枠**: 幅 3.6mm
    - **枠間隔**: 1.0mm
    - **ハイフン部**: 3桁目と4桁目の間に 4.0mm のスペースを挿入
    - **ハイフン文字**: 出力しない

| 6 | 3.6mm | 1.0mm | |

## 3. その他の要素

| 要素 | 配置基準 | 備考 |
|:---|:---|:---|
| **宛先住所** | 上端: 30mm, 右端: 15mm | 縦書き。長い住所は自動改行されないため要調整 |
| **宛名（氏名）** | 中央配置 | 縦書き。連名がある場合は並べて表示 |
| **差出人情報** | 下端: 18mm, 左端: 10mm | 縦書き。住所と氏名を改行して表示 |

## 4. 印刷設定

- **用紙サイズ**: 100mm × 148mm (はがき)
- **余白設定**: 上下左右 0mm
- **@media print**: コンテナ要素の余白やパディングを全てリセットし、`position: absolute` または `fixed` で配置を再現
