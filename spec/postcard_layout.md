# 年賀ハガキ・宛名レイアウト仕様書

本アプリケーションにおける年賀ハガキ（宛名面）の要素配置に関する仕様を定義します。
配置は日本郵便の定形郵便物および年賀ハガキの推奨規格に基づいています。

## 1. 宛先郵便番号

印刷済みの7桁の赤枠に合わせて数字を配置します。

- **基準位置** (layout.css設定値):
    - **上端**: 上辺から 12.4mm
    - **右端**: 右辺から 9.8mm
    - 配置基準: 右上（Flexboxによる配置）

- **フォント**: `OCR-B`, `monospace` (等幅フォント推奨)
- **サイズ**: 13pt (約4.5mm)

- **文字配置 (ピッチ)**:
    - **各数字枠**: 幅 5.7mm
    - **枠間隔**: 1.3mm
    - **ハイフン部**: 3桁目と4桁目の間に 7.2mm のスペースを挿入
    - **ハイフン文字**: 出力しない

| 1 | 5.7mm | 1.3mm | |

## 2. 差出人郵便番号

ハガキ左下の差出人枠に合わせて配置します。

- **基準位置**:
    - **下端**: 下辺から 32.0mm
    - **左端**: 左辺から 12.0mm

- **フォントサイズ**:
    - 郵便番号: 10pt
    - 住所・氏名: 1.3rem (約21px) - 下揃え配置

- **文字配置 (ピッチ)**:
    - **各数字枠**: 幅 3.6mm
    - **枠間隔**: 1.0mm
    - **ハイフン部**: 3桁目と4桁目の間に 4.0mm のスペースを挿入
    - **ハイフン文字**: 出力しない

## 3. その他の要素

| 要素 | 配置基準 | 備考 |
|:---|:---|:---|
| **宛先住所** | 上端: 30mm, 右端: 15mm | 縦書き。長い住所は自動改行されないため要調整 |
| **宛名（氏名）** | 中央配置 | 縦書き。連名がある場合は並べて表示 |
| **差出人情報** | 下端: 18mm, 左端: 10mm | 縦書き。住所と氏名を改行して表示 |

## 4. 印刷設定

- **用紙サイズ**: 100mm × 148mm (はがき)
- **余白設定**: 上下左右 0mm
- **@media print**: コンテナ要素の余白やパディングを全てリセットし、`position: absolute` または `fixed` で配置を再現
- **デバッグ要素**: `debug-panel` や枠線などは印刷時に `display: none` となり出力されない

## 5. レイアウト調整・デバッグ機能

ブラウザ上でレイアウトを微調整する機能を提供しています（`js/debug.js`, `css/debug.css`）。

- **位置・間隔調整**:
    - 各要素の X/Y 座標を 0.1mm 単位で調整可能。
    - 郵便番号の文字間隔（通常・ハイフン部）を個別に調整可能。
    - 調整値は `localStorage` に保存され永続化される。
- **視覚補助**:
    - **グリッド**: 背景に5mm方眼を表示。
    - **枠線**: 各要素の領域（バウンディングボックス）を `outline` 表示。レイアウトシフトなし。
    - **1mm定規**: 郵便番号枠の周囲に1mm刻みの目盛りを表示。
    - **背景画像**: スキャンしたハガキ画像を半透明で重ねて比較可能。
- **CSSエクスポート**:
    - 現在の調整値をCSSスニペットとして生成・コピー可能。
