# らくらく宛名印刷

![Project Status: Alpha](https://img.shields.io/badge/project_status-alpha-orange)

> [!CAUTION]
> **本プロジェクトは現在アルファ版（開発途上）です。**
> 予期せぬ挙動やレイアウトのずれが発生する可能性があります。
> **実際にハガキに印刷する際は、必ず事前に普通紙等でテストプリントを行い、位置が正しいことを確認してください。**

プレミアムなデザインと直感的な操作性を備えた、ハガキ宛名印刷専用のWebアプリケーションです。
ブラウザだけで動作し、データはすべてお使いのPC内（IndexedDB）に安全に保存されます。

## 特徴

- **インストール不要**: `index.html` をブラウザで開くだけですぐに使用可能。
- **プライバシー保護**: サーバーとの通信を行わず、住所録データは完全にローカルで管理されます。
- **美しい縦書き**: 日本のハガキに最適な縦書きレイアウトを自動調整。
- **郵便番号対応**: 枠に合わせた数字の自動配置。
- **一発印刷**: CSSで最適化されたハガキサイズ（100mm x 148mm）での印刷が可能。

## 使い方

1. `index.html` を Chrome や Safari などのモダンブラウザで開きます。
2. 「新規連絡先」から宛名を追加します。
3. リストから宛名を選択すると、右側にプレビューが表示されます。
4. 「設定」ボタンからご自身の（差出人）情報を登録します。
5. 「印刷する」ボタンを押し、プリンターの用紙設定を「ハガキ」にして印刷してください。

## 技術スタック

- **Frontend**: Vanilla HTML, CSS, JavaScript (ES Modules)
- **Database**: IndexedDB (Dexie.js)
- **Styling**: Vanilla CSS (CSS Grid, Flexbox, Variable system)
- **Fonts**: Inter, Outfit, 游明朝 (System default)

## 開発者向け

ビルドステップはありません。ファイルを直接編集して機能を拡張できます。
印刷レイアウトの微調整は `css/print.css` を変更してください。
