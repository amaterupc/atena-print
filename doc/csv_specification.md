# CSVインポート/エクスポート仕様書

本アプリケーションにおける住所録データのCSV取り扱い仕様を定義します。

## 1. ファイル形式
- **拡張子**: `.csv`
- **文字エンコーディング**: UTF-8 (BOM付き推奨)
- **改行コード**: CR+LF または LF

## 2. データ構造 (列定義)

### 現行フォーマット（v3）

| 列 | 項目名 | 必須 | 説明 | 例 |
| :---: | :--- | :---: | :--- | :--- |
| 1 | 姓 | ○ | 苗字 | 山田 |
| 2 | 名 | ○ | 名前 | 太郎 |
| 3 | 敬称 | - | 様/殿/御中/先生/ちゃん/くん/空欄 | 様 |
| 4 | 姓2 | - | 連名2人目の苗字（空欄で1人目と同姓） | |
| 5 | 名2 | - | 連名2人目の名前 | 花子 |
| 6 | 敬称2 | - | 連名2人目の敬称 | 様 |
| 7 | 姓3 | - | 連名3人目の苗字 | |
| 8 | 名3 | - | 連名3人目の名前 | 次郎 |
| 9 | 敬称3 | - | 連名3人目の敬称 | くん |
| 10 | 郵便番号 | ○ | ハイフンあり推奨 | 100-0001 |
| 11 | 住所 | ○ | 送付先住所 | 東京都千代田区1-1 |
| 12 | カテゴリ | - | 分類 | 親戚 |
| 13 | 2025送付 | - | ○ または空欄 | ○ |
| 14 | 2025受取 | - | ○ または空欄 | ○ |
| 15 | 2026送付 | - | ○ または空欄 | |
| 16 | 2026受取 | - | ○ または空欄 | |

## 3. インポート時の動作
- **ヘッダー行**: 1行目に「姓」「名前」「name」を含む場合、自動でスキップします。
- **後方互換性**: 以前の形式（姓名分離版、名前一括版）も自動判別してインポート可能です。
- **引用符**: ダブルクォートで囲まれたフィールド内のカンマは区切りとして扱いません。
- **年賀状フラグ**: `○` または `true` で送付/受取済みとして設定されます。
- **文字コード**: UTF-8 と Shift-JIS を自動判別します。

### 対応外部フォーマット

#### エプソン カラリオ年賀 CSV
カラリオ年賀からエクスポートしたCSV（Shift-JIS）をそのままインポート可能です。

| カラリオ列 | マッピング先 |
|-----------|-------------|
| 姓 | 姓 |
| 名 | 名 |
| 敬称 | 敬称 |
| 自宅7桁〒 | 郵便番号 |
| 住所１ + 住所２ | 住所 |
| 連名1 | 名2 |
| 連姓1 | 姓2 |
| 敬称(連名１) | 敬称2 |
| 連名2 | 名3 |
| 連姓2 | 姓3 |
| 敬称(連名２) | 敬称3 |

## 4. エクスポート時の動作
- **BOM付きUTF-8** でExcel互換形式として出力します。
- すべてのフィールドはダブルクォートで囲まれます。
- 年賀状の送付/受取状況は `○` または空欄で出力されます。

## 5. CSVサンプル

### 完全フォーマット
```csv
姓,名,敬称,姓2,名2,敬称2,姓3,名3,敬称3,郵便番号,住所,カテゴリ,2025送付,2025受取,2026送付,2026受取
山田,太郎,様,山田,花子,様,,,様,100-0001,東京都千代田区千代田1-1,友人,○,○,,
佐藤,一郎,殿,,,,,,様,150-0002,東京都渋谷区渋谷2-2-2,仕事,,,○,
```

### 最小構成（後方互換）
```csv
姓,名,郵便番号,住所
鈴木,次郎,160-0003,東京都新宿区西新宿3-3-3
```
